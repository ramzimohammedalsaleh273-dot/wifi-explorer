# كاشف الشبكات الذكي — WiFi Explorer

تطبيق Flutter بواجهة عربية RTL لفحص شبكات Wi‑Fi القريبة والبحث عن نقاط اتصال عامة مسجلة في بيانات OpenStreetMap.

## الوظائف الموجودة في المشروع
- **Android:** فحص الشبكات القريبة عبر واجهات Android الأصلية، مع عرض اسم الشبكة ومعرّف نقطة البث وقوة الإشارة والتردد والقناة ونوع الحماية، وفق الأذونات والقيود التي يفرضها النظام.
- **Windows:** فحص الشبكات القريبة باستخدام أداة Windows المدمجة `netsh`. يعرض مؤشر الإشارة كنسبة مئوية، وليس dBm.
- البحث حسب اسم مدينة أو منطقة حول العالم، ثم استعراض نقاط اتصال عامة ومقاهي إنترنت مسجلة ضمن نطاق 10 كم في OpenStreetMap.
- فتح نتيجة الخريطة في OpenStreetMap، ومفضلة وسجل محفوظان محليًا على الجهاز.
- فحص الشبكات القريبة يعمل دون إنترنت بعد منح الأذونات؛ البحث العام يحتاج اتصالًا بالإنترنت.

## البناء والتنزيل
توجد عمليتا بناء آليتان عبر GitHub Actions:
- **Android APK:** افتح [عمليات بناء Android](https://github.com/ramzimohammedalsaleh273-dot/wifi-explorer/actions/workflows/build-android.yml)، واختر تشغيلًا ناجحًا، ثم نزّل الملف من قسم Artifacts باسم `wifi-explorer-apk`.
- **Windows:** افتح [عمليات بناء Windows](https://github.com/ramzimohammedalsaleh273-dot/wifi-explorer/actions/workflows/build-windows.yml)، واختر تشغيلًا ناجحًا، ثم نزّل `wifi-explorer-windows`. فك الضغط وشغّل `wifi_explorer.exe` من مجلد الإصدار. قد تحتاج إلى إبقاء ملفات DLL المرفقة بجانبه.

يُشغّل كل دفع إلى الفرع `main` عمليات البناء والاختبارات تلقائيًا. لا تعتبر النسخة جاهزة للتثبيت حتى ينتهي التشغيل بنجاح وتظهر ملفات Artifacts.

## التشغيل محليًا
ثبّت Flutter SDK، ثم نفّذ:
```bash
flutter pub get
flutter test
flutter run
```

## حدود مهمة
- لا يمكن لأي تطبيق جعل الهاتف يلتقط إشارة راديوية بعيدة لا تصل إلى جهازه. البحث العالمي يعرض **بيانات عامة مسجلة** عن مواقع يُحتمل توفر Wi‑Fi فيها، ولا يؤكد أن الشبكة تعمل حاليًا.
- بيانات OpenStreetMap قد تكون ناقصة أو قديمة، ولا تمثل قاعدة بيانات لكل أجهزة الراوتر.
- لا يستخرج التطبيق كلمات مرور الشبكات المحمية ولا يحاول تجاوز حمايتها.
- قيود Android قد تمنع الفحص المتكرر أو تعرض رسائل طلب الأذونات؛ راجع إعدادات Wi‑Fi والموقع إذا تعذر الفحص.
- لا يرفع التطبيق نتائج الفحص القريب إلى خادم خاص به. عند طلب البحث العام، يتصل بخدمات Nominatim وOverpass العامة ويفتح روابط خرائط OpenStreetMap.
