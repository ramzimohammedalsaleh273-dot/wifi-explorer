# كاشف الشبكات الذكي — WiFi Explorer

تطبيق Flutter عربي لفحص شبكات Wi‑Fi القريبة على Android، وعرض معلومات الإشارة والتردد والقناة والحماية، مع البحث عن نقاط اتصال عامة موثقة في OpenStreetMap عند توفر الإنترنت.

## تنبيه تقني مهم
- فحص الشبكات الراديوية القريبة يعمل على Android فقط، ويخضع لأذونات النظام وسياسات إصدار Android والجهاز.
- إصدار الويب/Windows لا يستطيع إجراء مسح راديو Wi‑Fi بالطريقة نفسها عبر المتصفح؛ يحتاج دعمًا خاصًا بالمنصة.
- لا يستخرج التطبيق كلمات مرور الشبكات المحمية.
- قاعدة بيانات نقاط الاتصال العامة مبنية على وسوم OpenStreetMap وليست ماسحًا عالميًا لكل أجهزة الراوتر، ولا تحتوي على كلمات مرور افتراضيًا.

## البناء
يُبنى APK عبر GitHub Actions عند دفع التغييرات إلى `main`. افتح تبويب Actions ثم اختر آخر تشغيل ناجح ونزّل artifact باسم `wifi-explorer-apk`.

## التشغيل المحلي
ثبّت Flutter SDK ثم نفّذ:
```bash
flutter pub get
flutter run
```

## الخصوصية
لا يرسل التطبيق نتائج المسح القريب إلى خادم خاص به. البحث العام يرسل طلبًا إلى خدمة Overpass API الخاصة ببيانات OpenStreetMap عند طلب البحث فقط.
